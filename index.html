HOW IT WORKS

Pair once.
Then just flick.

01

Pair once

Open Fling on both devices on the same Wi‑Fi. One shows a six‑digit code, you type it on the other. After that they find each other on their own.

02

Flick it off the edge

Pick a photo, a video, a file or a link and throw it toward the other device. It leaves your screen the moment it crosses the edge.

03

It lands

The card glides in on the other screen with the same speed and angle, sharp preview first, full file right behind it. Open, save, share or throw it back.

FIRST RUNONCE PER DEVICE

Three clicks,
then never again.

Mac

Unzip, drag Fling to Applications, open it. macOS says it can't check the developer: go to System Settings → Privacy & Security → Open Anyway. Once.

Android

Open the APK, allow “install from this source” once, Install. Fling asks for its few permissions on first launch, each row turns into a check.

Windows

Run the installer. On “Windows protected your PC” click More info → Run anyway. If Windows asks about the firewall, allow private networks.

Updates: every app tells you when a newer version is here and installs it with one tap.
